# percentileFromKLL

Extracts the approximate value at a specified percentile from a serialized KLL quantiles sketch created by [serializedKLL](/docs/en/sql-reference/aggregate-functions/reference/serializedkll) or [mergeSerializedKLL](/docs/en/sql-reference/aggregate-functions/reference/mergeserializedkll).

KLL (Kolmogorov-Lerch-Lifschitz) sketches provide better space efficiency (35-60% smaller) than classic quantiles sketches while maintaining formal accuracy guarantees.

## Syntax

```sql
percentileFromKLL(sketch, percentile)
```

## Arguments

- `sketch` — Serialized KLL quantiles sketch. Type: [String](/docs/en/sql-reference/data-types/string.md).
- `percentile` — Percentile value between 0.0 and 1.0. Type: [Float64](/docs/en/sql-reference/data-types/float.md).
  - 0.0 = minimum value
  - 0.5 = median
  - 0.95 = 95th percentile
  - 0.99 = 99th percentile
  - 1.0 = maximum value

## Returned Value

- Approximate value at the specified percentile. Type: [Float64](/docs/en/sql-reference/data-types/float.md).
- Returns NaN if the sketch is empty or invalid.

## Implementation Details

- Uses the Apache DataSketches KLL algorithm for percentile estimation
- 35-60% smaller than classic quantiles sketches for same accuracy
- Provides formal rank-based accuracy guarantees (~1.65% rank error at 99% confidence with default K=200)
- Very fast: typically microseconds regardless of dataset size
- Monotonic: percentileFromKLL(s, p1) ≤ percentileFromKLL(s, p2) when p1 ≤ p2
- Compatible with Apache DataSketches format (Java, Python, Go implementations)

## Usage

### Basic Percentile Extraction

```sql
SELECT percentileFromKLL(latency_sketch, 0.95) AS p95_latency
FROM service_metrics
WHERE service = 'api';
```

### Multiple Percentiles

```sql
SELECT 
    service,
    percentileFromKLL(latency_sketch, 0.50) AS p50,
    percentileFromKLL(latency_sketch, 0.95) AS p95,
    percentileFromKLL(latency_sketch, 0.99) AS p99
FROM hourly_metrics
WHERE hour = toStartOfHour(now());
```

## Examples

### Example 1: Service Latency Percentiles

```sql
WITH sketch AS (
    SELECT serializedKLL(response_time_ms) AS s
    FROM requests
    WHERE service = 'api' AND date = today()
)
SELECT 
    percentileFromKLL(s, 0.50) AS median_ms,
    percentileFromKLL(s, 0.95) AS p95_ms,
    percentileFromKLL(s, 0.99) AS p99_ms,
    percentileFromKLL(s, 0.999) AS p999_ms
FROM sketch;
```

```response
┌─median_ms─┬──p95_ms─┬──p99_ms─┬─p999_ms─┐
│     45.2  │   156.8 │   287.3 │   521.7 │
└───────────┴─────────┴─────────┴─────────┘
```

### Example 2: Cross-Service Analytics with Kafka

```sql
-- Consume KLL sketches from Kafka messages (generated by Go service)
SELECT 
    service,
    percentileFromKLL(mergeSerializedKLL(kll_sketch_bytes), 0.50) AS p50,
    percentileFromKLL(mergeSerializedKLL(kll_sketch_bytes), 0.95) AS p95
FROM kafka_edge_metrics
GROUP BY service;
```

### Example 3: Time-Series Percentile Analysis

```sql
SELECT 
    toStartOfHour(timestamp) AS hour,
    percentileFromKLL(
        serializedKLL(query_duration_ms), 
        0.95
    ) AS p95_query_duration
FROM query_log
WHERE timestamp >= now() - INTERVAL 24 HOUR
GROUP BY hour
ORDER BY hour;
```

### Example 4: Merged Sketches Across Regions

```sql
WITH regional_sketches AS (
    SELECT 
        region,
        serializedKLL(response_time_ms) AS sketch
    FROM requests
    WHERE date = today()
    GROUP BY region
),
global_sketch AS (
    SELECT mergeSerializedKLL(sketch) AS merged
    FROM regional_sketches
)
SELECT 
    percentileFromKLL(merged, 0.50) AS global_median,
    percentileFromKLL(merged, 0.95) AS global_p95,
    percentileFromKLL(merged, 0.99) AS global_p99
FROM global_sketch;
```

### Example 5: Percentile Range

```sql
-- Get percentiles from 0% to 100% in 10% increments
SELECT 
    number / 10.0 AS percentile,
    percentileFromKLL(
        (SELECT serializedKLL(latency_ms) FROM requests), 
        number / 10.0
    ) AS value
FROM numbers(11);
```

## Performance Notes

- Constant time execution regardless of dataset size
- Can efficiently query many percentiles from the same sketch
- No memory overhead beyond the sketch itself
- 35-60% smaller than classic quantiles sketches

## Error Handling

- Invalid percentile values (< 0 or > 1) throw an exception
- Empty or corrupted sketches return NaN
- NULL sketches return NaN
